Extraomnes.

“Everyone out” · said before the doors are locked

A tri-vendor code review panel for AI coding agents.

A conclave is not a meeting. It is a room that stays shut until the count is done, and a rule that nobody's word is taken for the count.

Nihil creditur. Omnia probantur. Nothing is believed · everything is proven

I · The correspondence

The rite already describes the machine

very part of this runtime has a name older than software, because the problem is older than software: how a body of people reaches a decision that nobody present can quietly fix.

  • Scrutatores — three, chosen by lot, who open the ballots and read them aloud.Three seats, each a separate vendor session. A seat that cannot show its session, its tokens and the model that answered does not count.
  • The third scrutineer recounts what the first two have already counted.A checking seat never runs on the builder’s vendor, and a third vendor takes the review wherever the class allows one. One vendor’s blind spot cannot pass unseen.
  • Revisores — three more, who review the scrutineers' own count before it is announced.The count is re-derived from the receipts rather than read back from what the seats said about it.
  • Advocatus diaboli — appointed to argue against, so assent is not mistaken for agreement. Borrowed, not a conclave office: the devil's advocate belongs to canonisation proceedings.An approval carrying no reason of its own counts as an abstention.
  • The Master of Ceremonies calls extra omnes, orders the room cleared, and walks out with everyone else. He runs the procedure and holds no vote.The host session drives the run and calls the tools. It is not a seat. HOST_MODES lists the places it may run from, never a list of voters.
  • Chosen by lot — the scrutineers are drawn, not appointed, so nobody can arrange who does the counting.The arbiter proposes the seats from the routing matrix under a margin rule, and is barred from sitting one. Not randomness: a choice that has to show its numbers, which deterministic code can then overrule.
  • Cum clave — with a key. Nothing enters and nothing leaves until it is settled.The plan is sealed and hashed before the first process starts. A route the matrix does not allow is refused before a vendor is called.
  • Each ballot is pierced through the word Eligo with a needle and thread, and the thread is tied, so none can be added or taken away afterwards.Receipts are bound into one committed transaction with the plan entry, the plan hash and the artifact hashes. A duplicate logical dispatch cannot create a second successful row.
  • The ballots are burned. For centuries the smoke was the only announcement — until 2005, when bells were added, because the smoke could not reliably be read.The same failure, answered the same way. Two outcomes are written as themselves, and an outcome word this build cannot read is a split, never a passage. Nothing is inferred from the colour of anything.

Where it does not hold, it is said here. The historical three scrutineers all counted; this runtime has two voting checkers, a builder that never votes, and code that does the counting. The rite is the older answer to the same problem, not a blueprint this was built from.

III · The route

One unit, from block to smoke

A lead writes a fenced block. Everything after that is decided by the matrix and counted in code. The current runs left to right; nothing flows back.

Choose a stage to see what it decides and what it has to prove.

Five parties in the room. Two counted votes. The host drives and does not vote; the builder’s tree moved, so its receipt cannot count; the arbiter proposes and is barred from sitting a seat at all.

IV · The canon

What makes a vote a vote

  1. Evidence, not assentAn approval carrying no reason of its own counts as an abstention. Agreement is not evidence.
  2. Proof of the seatThe vendor session, the token count, and the model that actually answered. Missing any of the three, the vote does not count.
  3. An unchanged treeBoth trees or neither. A missing write audit is a check that did not run, and a check that did not run allows nothing.
  4. The gate, never a voteA unit whose own check failed does not land, whatever the seats said. The check gates the act; it never joins the count.
  5. Silence is refusalAn outcome this build cannot read is a split. A newer runtime can never land work in an older one that cannot tell what it meant.
