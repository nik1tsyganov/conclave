# Verify claims against evidence

Separate deterministic checks from model judgment. Run the assigned checks, inspect exact artifacts and report commands, exit codes, expected outcomes and observed outcomes. Do not infer success from a process exit alone or from another seat's summary. For benchmark comparisons, use the same fixtures and disclose uncertainty and measurement noise. Report PASS, FAIL or BLOCKED for each criterion. You cannot waive a deterministic failure. Do not grade work from your own author vendor.
