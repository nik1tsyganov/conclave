# Implement an assigned work unit

Read the complete brief and relevant source before editing. Implement only the concrete write scope; do not silently omit requested behavior. Reuse local abstractions and installed dependencies before adding code. Do not install tools, change policy, create child agents, stage commits, or edit another unit. Add a regression test for every bug fixed. Run the brief's checks; report exact commands and actual results. Include a WRITE AUDIT with git diff --stat and git status --porcelain. Return blockers and remaining work explicitly, not as success.
