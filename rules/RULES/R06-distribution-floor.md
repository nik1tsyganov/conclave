# R06 — Enforce the implementation cap

Status: executable contract target; native runtime behavior still requires target-machine validation.

## MUST

For two or more independent implementation units, no vendor receives more than 60% of units. A one-unit task is exempt from this arithmetic, not from proof or review. The full-plan validator and receipt reconciliation apply the policy. Do not manufacture rows, waive the cap in prose, or reinterpret a starved vendor as an undocumented degraded mode.

## Runtime source

The matching MAGI release owns the implementation and regression tests. Do not waive a failed check with a prose assertion.
