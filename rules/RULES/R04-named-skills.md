# R04 — Stage minimal seat capabilities

Status: executable contract target; native runtime behavior still requires target-machine validation.

## MUST

The runtime derives a vendor leaf profile, role skills and class supplements from `seat-profiles.json`, stages their actual files, and verifies the digest manifest before and after execution. Routing, bridge, orchestration, distribution and retrospective skills are coordinator-only. A globally visible skill is not automatically authorized. Copying a skill name into prose is not an enforcement mechanism.

## Runtime source

The matching MAGI release owns the implementation and regression tests. Do not waive a failed check with a prose assertion.
